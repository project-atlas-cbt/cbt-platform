# Recorded interface sounds

Real recordings from BigSoundBank (bigsoundbank.com), all licensed CC0 (public domain), cut to
their first event and normalised. No music, no pitched tones.

| File        | Source                               |
| ----------- | ------------------------------------ |
| `click.wav` | Raspberry mouse single click (s1735) |
| `page.wav`  | Pages that turn 2 (s1413)            |
| `thunk.wav` | Wooden drawer closing (s1500)        |
