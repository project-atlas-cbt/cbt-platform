# User guides

**Status:** F21 (2026-10-05), DoD 7. Plain-language guides handed to a school at onboarding
([school-onboarding.md](../operations/school-onboarding.md#what-we-hand-the-school)). They name
no product: the platform's name comes from configuration (`PROJECT.md`). `<school>.<root>` is the
school's own address, for example `https://kingscollege.<root>`.

| Guide                                                   | For                                                 |
| ------------------------------------------------------- | --------------------------------------------------- |
| [Teacher guide](teacher.md)                             | Teachers and HODs: questions, exams, results        |
| [Invigilator guide](invigilator.md)                     | Whoever runs a sitting in the lab                   |
| [Student instructions](student.md)                      | Students, read aloud or printed before a sitting    |
| [School onboarding](../operations/school-onboarding.md) | The school admin, from activation to the first exam |
| [Lab preparation](../operations/lab-preparation.md)     | The lab contact, before the first sitting           |

When the product changes a screen named here, update the guide in the same change.
